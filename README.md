# Social Correction Experiment Analsysis Code

This repo contains the code for the published studies conducted under the PhD thesis **Towards Better Truth Discernment on Social Media**. The three folders _Experiment 1, Experiment 2 and Experiment 3_ contains the R (Rmd) code used to analyse the data from the participants. The experiments were conducted using a custom made web application.

## Experiment 1

This online experiment investigates how social media users react when they are corrected by another user after sharing misinformation.

Visit the [full manuscript](https://aisel.aisnet.org/acis2023/17/) for more details and results.

**Recommended Citation**

Vithanage, Sameera; Mendoza, Antonette; Ransom, Keith; and Karunasekera, Shanika, "Towards Better Truth Discernment on Social Media" (2023). ACIS 2023 Proceedings. 17.
https://aisel.aisnet.org/acis2023/17

---

## Experiment 2

This online experiment investigates how social media users react when they are _required_ to provide either corrective or endorsing responses to social media posts they encounter online.

---

## Experiment 3

This online experiment investigates how social media users react and behave they are given the option to provide corrective or endorsing responses or withhold responding to social media posts they encounter online.

Visit the [full manuscript](https://aisel.aisnet.org/ecis2025/cog_hbis/cog_hbis/7/) for more details and results.

**Recommended Citation**

Vithanage, Sameera S.; Ransom, Keith James; Mendoza, Antonette; and Karunasekera, Shanika, "SOCIAL CORRECTION ON SOCIAL MEDIA: A QUANTITATIVE ANALYSIS OF COMMENT BEHAVIOUR AND RELIABILITY" (2025). ECIS 2025 Proceedings. 7. https://aisel.aisnet.org/ecis2025/cog_hbis/cog_hbis/7
